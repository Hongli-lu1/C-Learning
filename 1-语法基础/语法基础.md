## 1. 变量、常量与基本类型

变量是存放数据的“盒子”，声明时指定类型。

```csharp
int age = 18;              // 32 位整数
long population = 8_000_000_000L;   // 下划线可作分隔，L 表示 long
double price = 9.99;       // 双精度浮点
float ratio = 0.5f;        // 单精度，需要 f 后缀
decimal money = 19.99m;    // 高精度小数，金额用 m
bool isReady = true;       // 布尔
char grade = 'A';          // 单个字符，单引号
string name = "Alice";     // 字符串，双引号

// var：由编译器推断类型（右侧必须能确定类型）
var count = 10;            // 推断为 int
var title = "C#";          // 推断为 string

// const：编译期常量，必须赋值，不能修改
const double Pi = 3.14159;

// readonly：运行期只读字段（本处演示字段用法，后面 OOP 会深入）
Console.WriteLine($"{name} {age} {price} {money} {isReady} {grade}");
```

### 常用整型一览

| 类型 | 大小 | 范围 |
|---|---|---|
| `byte` | 1 字节 | 0 ~ 255 |
| `short` | 2 字节 | -32768 ~ 32767 |
| `int` | 4 字节 | ±21 亿 |
| `long` | 8 字节 | ±9.2×10¹⁸ |
| `float` | 4 字节 | 单精度浮点 |
| `double` | 8 字节 | 双精度浮点 |
| `decimal` | 16 字节 | 高精度，适合金额 |
| `bool` | 1 字节 | true / false |
| `char` | 2 字节 | 单个 Unicode 字符 |

> **默认**：整数用 `int`，小数用 `double`，金额用 `decimal`。

## 2. 字面量

字面量就是代码里直接写出的值。

```csharp
int dec = 100;          // 十进制
int hex = 0xFF;         // 十六进制 → 255
int bin = 0b1010;       // 二进制 → 10
long big = 1_000_000L;  // 长整型后缀 L
double d = 1.5;         // double
float f = 1.5f;         // float 后缀 f
decimal m = 1.5m;       // decimal 后缀 m
char c = '\n';          // 转义字符：换行
string s = "C:\\path";  // 反斜杠需转义
string raw = @"C:\path";// @：原样字符串，不转义

Console.WriteLine($"{dec} {hex} {bin} {big} {d} {f} {m}");
```

常用转义字符：`\n` 换行、`\t` 制表、`\\` 反斜杠、`\"` 双引号、`\'` 单引号。

## 3. 运算符

### 3.1 算术运算符

```csharp
int a = 7, b = 3;
Console.WriteLine(a + b);   // 10
Console.WriteLine(a - b);   // 4
Console.WriteLine(a * b);   // 21
Console.WriteLine(a / b);   // 2   ← 整数相除，取整
Console.WriteLine(a % b);   // 1   ← 取余
Console.WriteLine(7.0 / 3); // 2.333...  ← 有浮点就按浮点算
```

> ⚠️ 陷阱：`7 / 3` 是 `2`。要小数结果，至少一边写成 `7.0`。

### 3.2 赋值与复合运算符

```csharp
int x = 10;
x += 5;   // x = x + 5 → 15
x -= 3;   // 12
x *= 2;   // 24
x /= 4;   // 6
x %= 4;   // 2
x++;      // 自增 1 → 3
x--;      // 自减 1 → 2
Console.WriteLine(x);
```

### 3.3 比较与逻辑运算符

```csharp
int a = 5, b = 8;
Console.WriteLine(a > b);    // False
Console.WriteLine(a == b);   // False
Console.WriteLine(a != b);   // True

bool ok = a < b && b > 0;    // && 与
bool any = a > 100 || b > 0; // || 或
bool not = !ok;              // ! 非
Console.WriteLine($"{ok} {any} {not}");
```

> 短路求值：`&&` 左边为 false 就不再算右边；`||` 左边为 true 就不再算右边。

### 3.4 位运算符

```csharp
int p = 0b1100;  // 12
int q = 0b1010;  // 10
Console.WriteLine(p & q);   // 1000 → 8   与
Console.WriteLine(p | q);   // 1110 → 14  或
Console.WriteLine(p ^ q);   // 0110 → 6   异或   不同为1
Console.WriteLine(~p);      // 按位取反
Console.WriteLine(p << 1);  // 左移 1 位 → 24
Console.WriteLine(p >> 1);  // 右移 1 位 → 6
```

### 3.5 三元运算符

```csharp
int score = 75;
string result = score >= 60 ? "及格" : "不及格";
Console.WriteLine(result);   // 及格
```

### 3.6 运算符优先级（由高到低，节选）

```
()  []  .  ++  --
! ~ * / %          (一元与乘除)
+ -                (加减)
<< >>              (移位)
< > <= >=          (比较)
== !=              (相等)
&                  (按位与)
^                  (异或)
|                  (按位或)
&&
||
?:
=
```

> 记不住就用括号，可读性优先。

## 4. 流程控制

### 4.1 if / else if / else

```csharp
int score = 85;
if (score >= 90)
    Console.WriteLine("优秀");
else if (score >= 75)
    Console.WriteLine("良好");
else if (score >= 60)
    Console.WriteLine("及格");
else
    Console.WriteLine("不及格");
// 输出：良好
```

### 4.2 switch

```csharp
int day = 3;
switch (day)
{
    case 1:
        Console.WriteLine("周一");
        break;
    case 2:
    case 3:
        Console.WriteLine("周二或周三");
        break;
    default:
        Console.WriteLine("其他");
        break;
}
// 输出：周二或周三
```

### 4.3 switch 表达式（C# 8+，更简洁）

```csharp
string Grade(int s) => s >= 90 ? "A" : s >= 60 ? "B" : "C";

int score = 88;
string g = score switch
{
    >= 90 => "A",
    >= 60 => "B",
    _ => "C"
};
Console.WriteLine(g);   // B
```

### 4.4 for 循环

```csharp
for (int i = 1; i <= 5; i++)
    Console.Write($"{i} ");   // 1 2 3 4 5
Console.WriteLine();
```

### 4.5 while / do-while

```csharp
int n = 3;
while (n > 0)
{
    Console.Write($"{n} ");   // 3 2 1
    n--;
}
Console.WriteLine();

int m = 0;
do
{
    Console.Write("至少执行一次 ");   // 会先执行一次
    m++;
} while (m < 0);
Console.WriteLine();
```

### 4.6 foreach




```csharp
string[] names = { "Tom", "Jerry", "Spike" };
foreach (var name in names)
    Console.Write($"{name} ");   // Tom Jerry Spike
Console.WriteLine();
```



### 4.7 break / continue / goto

```csharp
for (int i = 1; i <= 10; i++)
{
    if (i == 5) continue;   // 跳过 5
    if (i == 8) break;      // 到 8 停止
    Console.Write($"{i} "); // 1 2 3 4 6 7
}
Console.WriteLine();
```

## 5. 字符串

### 5.1 声明与插值

```csharp
string name = "Alice";
int age = 25;

string a = "名字：" + name;          // 拼接
string b = $"名字：{name}，年龄：{age}";  // 字符串插值（推荐）
string c = $"明年 {age + 1} 岁";      // 插值里可写表达式
string path = @"C:\Users\Admin";     // @ 原样字符串

Console.WriteLine(b);
Console.WriteLine(c);
Console.WriteLine(path);
```

### 5.2 常用方法

```csharp
string s = "  Hello World  ";
Console.WriteLine(s.Trim());                 // 去掉首尾空格
Console.WriteLine(s.Trim().ToUpper());       // HELLO WORLD
Console.WriteLine(s.Contains("World"));      // True
Console.WriteLine(s.Replace("World", "C#")); // 替换
Console.WriteLine(s.Split(' ').Length);      // 按空格切分
Console.WriteLine("abc".Length);             // 3
Console.WriteLine("abc"[0]);                 // a
Console.WriteLine($"{"abc"}".Substring(1)); // bc
Console.WriteLine(string.IsNullOrEmpty("")); // True
Console.WriteLine(string.Join("-", new[] { "a", "b", "c" })); // a-b-c
```

### 5.3 可变字符串 StringBuilder

```csharp
using System.Text;

var sb = new StringBuilder();
for (int i = 0; i < 5; i++)
    sb.Append(i).Append(',');
Console.WriteLine(sb.ToString());   // 0,1,2,3,4,
```

> 大量拼接字符串时，`StringBuilder` 比 `+` 更高效（第 8 章“内存与性能”会讲原理）。

### 5.4 原始字符串（C# 11+）

```csharp
string json = """
    { "name": "Alice", "age": 25 }
    """;
Console.WriteLine(json);
```

## 6. 数组

### 6.1 一维数组

```csharp
int[] nums = { 3, 1, 4, 1, 5 };
Console.WriteLine(nums.Length);   // 5
Console.WriteLine(nums[0]);       // 3

nums[0] = 9;                      // 修改
Array.Sort(nums);                 // 排序
Console.WriteLine(string.Join(",", nums)); // 1,1,3,4,9

int[] zeros = new int[3];         // { 0, 0, 0 }
```

### 6.2 多维数组

```csharp
int[,] grid = new int[2, 3]
{
    { 1, 2, 3 },
    { 4, 5, 6 }
};
Console.WriteLine(grid[1, 2]);    // 6

for (int i = 0; i < grid.GetLength(0); i++)
    for (int j = 0; j < grid.GetLength(1); j++)
        Console.Write($"{grid[i, j]} ");   // 1 2 3 4 5 6
Console.WriteLine();
```

### 6.3 交错数组（数组的数组）

```csharp
int[][] jagged = new int[3][];
jagged[0] = new[] { 1, 2 };
jagged[1] = new[] { 3, 4, 5 };
jagged[2] = new[] { 6 };

foreach (var row in jagged)
    Console.WriteLine(string.Join(",", row));
// 1,2
// 3,4,5
// 6
```

## 7. 枚举与结构体

### 7.1 枚举 enum

```csharp
enum OrderState
{
    Pending,     // 0
    Processing,  // 1
    Done,        // 2
    Cancelled    // 3
}

OrderState state = OrderState.Processing;
Console.WriteLine(state);                    // Processing
Console.WriteLine((int)state);               // 1
Console.WriteLine(state == OrderState.Done); // False

// 指定数值
enum HttpCode { OK = 200, NotFound = 404 }
Console.WriteLine((int)HttpCode.OK);         // 200
```

### 7.2 结构体 struct

```csharp
struct Point
{
    public int X;
    public int Y;

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }

    public override string ToString() => $"({X}, {Y})";
}

Point p = new Point(3, 4);
Console.WriteLine(p);              // (3, 4)
```

> `struct` 是**值类型**（第 10 节讲区别）；`enum` 适合表示有限状态集合，比用数字更清晰安全。

## 8. 方法

### 8.1 基本方法

```csharp
static int Add(int a, int b)
{
    return a + b;
}

Console.WriteLine(Add(3, 5));   // 8
```

### 8.2 方法重载（同名不同参数）

```csharp
static int Area(int side) => side * side;
static int Area(int w, int h) => w * h;
static double Area(double r) => Math.PI * r * r;

Console.WriteLine(Area(3));      // 9
Console.WriteLine(Area(3, 4));   // 12
Console.WriteLine(Area(1.0));    // 3.14159...
```

### 8.3 默认参数与命名参数

```csharp
static void Greet(string name, string prefix = "你好")
{
    Console.WriteLine($"{prefix}，{name}");
}

Greet("小明");                    // 你好，小明
Greet("Tom", "Hello");           // Hello，Tom
Greet(name: "Jerry", prefix: "Hi"); // 命名参数
```

### 8.4 params 可变参数

```csharp
static int Sum(params int[] nums)
{
    int total = 0;
    foreach (var n in nums) total += n;
    return total;
}

Console.WriteLine(Sum(1, 2, 3));       // 6
Console.WriteLine(Sum(1, 2, 3, 4, 5)); // 15
```

### 8.5 ref / out / in

```csharp
// ref：传入引用，方法内修改会影响外部
static void Increase(ref int x) => x++;

int a = 10;
Increase(ref a);
Console.WriteLine(a);   // 11

// out：方法负责赋值，用于返回多个结果
static bool TryDivide(int a, int b, out int result)
{
    if (b == 0) { result = 0; return false; }
    result = a / b;
    return true;
}

if (TryDivide(10, 2, out int q))
    Console.WriteLine(q);   // 5

// in：只读引用，避免大结构体复制
static void Print(in int value) => Console.WriteLine(value);
int v = 42;
Print(in v);
```

> 记忆：`ref` 进也出，`out` 只出不进，`in` 只进不出。

### 8.6 表达式体方法

```csharp
static int Square(int x) => x * x;
static string Name() => "C#";
Console.WriteLine($"{Square(4)} {Name()}");   // 16 C#
```

## 9. 类型转换

### 9.1 隐式转换（安全，自动）

```csharp
int i = 100;
long l = i;        // int → long，小范围转大范围
double d = i;      // int → double
Console.WriteLine($"{l} {d}");   // 100 100
```

### 9.2 显式转换（强制，可能丢数据）

```csharp
double d = 9.99;
int i = (int)d;    // 截断小数 → 9
Console.WriteLine(i);
```

### 9.3 字符串与数字互转

```csharp
// 数字 → 字符串
int n = 42;
string s1 = n.ToString();       // "42"

// 字符串 → 数字
string s2 = "123";
int a = int.Parse(s2);          // 123，失败会抛异常
bool ok = int.TryParse("abc", out int b);   // 安全：ok=false，b=0
Console.WriteLine($"{s1} {a} {ok} {b}");
```

### 9.4 Convert 与 as / is

```csharp
double dd = Convert.ToDouble("3.14");
Console.WriteLine(dd);            // 3.14

object obj = "hello";
if (obj is string str)            // is 类型检查 + 赋值（推荐）
    Console.WriteLine(str.Length); // 5

string? maybe = obj as string;    // as 转换，失败返回 null
Console.WriteLine(maybe);
```

> 口诀：**能不抛异常就用 `TryParse`；能 `is` 就别 `as`**。

## 10. 值类型 vs 引用类型

| 对比项 | 值类型 | 引用类型 |
|---|---|---|
| 例子 | `int`、`double`、`bool`、`char`、`struct`、`enum` | `string`、`class`、`array`、`object`、`delegate` |
| 存储位置 | 栈（局部变量） | 堆，变量存地址 |
| 赋值行为 | 复制值 | 复制引用（指向同一对象） |
| 默认值 | 0 / false / 空 struct | `null` |
| 能否为 null | 否（除非 `int?`） | 是 |

```csharp
// 值类型：各改各的
int x = 1;
int y = x;
y = 100;
Console.WriteLine($"{x} {y}");    // 1 100

// 引用类型：指向同一个对象
int[] arr1 = { 1, 2 };
int[] arr2 = arr1;
arr2[0] = 99;
Console.WriteLine(arr1[0]);       // 99  ← arr1 也变了

// string 是引用类型但“不可变”，赋值像值类型
string s1 = "a";
string s2 = s1;
s2 = "b";
Console.WriteLine(s1);            // a  （s2 指向了新对象）
```

## 11. 命名规范与代码风格

| 元素 | 规范 | 示例 |
|---|---|---|
| 类、方法、属性、枚举 | PascalCase | `OrderService`、`GetTotal()` |
| 局部变量、参数 | camelCase | `orderCount`、`userId` |
| 私有字段 | `_camelCase` | `_name` |
| 常量 | PascalCase | `MaxCount` |
| 接口 | `I` 开头 | `IDisposable` |
| 布尔 | 用 is/has/can 开头 | `isReady`、`hasItems` |

风格建议：

- 一行一个语句，`{ }` 即使单行也建议保留；
- 用有意义的命名，不用 `a`、`b`、`temp`；
- 用 `var` 仅在类型显而易见时（如 `var list = new List<int>();`）；
- 复杂条件用括号明确优先级；
- 注释解释“为什么”，不是“是什么”。

```csharp
// 好的写法
public int CalculateTotal(int unitPrice, int quantity)
{
    return unitPrice * quantity;
}

// 差的写法（无意义命名）
public int C(int a, int b) { return a * b; }
```

### 练习 7：猜数字游戏
用 `Random` 生成 1~100，`while` + `if` 提示“大了/小了”，记录次数。

```csharp
var rnd = new Random();
int target = rnd.Next(1, 101);
int tries = 0;
while (true)
{
    Console.Write("猜一个 1~100 的数: ");
    int guess = int.Parse(Console.ReadLine()!);
    tries++;
    if (guess < target) Console.WriteLine("小了");
    else if (guess > target) Console.WriteLine("大了");
    else { Console.WriteLine($"对了！用了 {tries} 次"); break; }
}
```
